One-line entry for [make.fun's "Dad Joke Showdown" bounty](https://make.fun/bounty/u-mfnakmal-dad-joke-showdown-1d2ce3e5): a single dad joke, at most 200 characters.

## How it works

`main.py` writes the joke to `$MAKEFUN_OUTPUT_DIR/entry.txt`. No network, no randomness, no model calls — the same line every run.

```text
I told my suitcase there would be no vacation this year. Now I'm dealing with emotional baggage.
```
